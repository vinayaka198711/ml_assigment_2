# Breast Cancer Diagnostic Classification Pipeline (WDBC)

An end-to-end Machine Learning pipeline utilizing the Wisconsin Diagnostic Breast Cancer (WDBC) dataset to classify cell nuclei biopsies as either Malignant or Benign. Features 5 production-grade ML architectures evaluated across 6 critical performance classification metrics alongside an interactive Streamlit inference engine.
